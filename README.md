## 🇬🇧 English
**Acme Security** is a dedicated open-source repository designed to serve as a security incident laboratory. It contains a collection of vital security documents, architectural maps, and logs that simulate real-world cyber events.

### ✨ Features
- 📊 **Log Analysis**: Contains API, WAF, Email, and Web logs in CSV format for deep diving into incidents.
- 🗺️ **Architecture**: Visual diagrams (`.png`) detailing the current system architecture.
- 🗓️ **Scheduling**: Includes security test schedules and submission records.

### 🛠️ Contents
- `api_logs.csv`, `waf_logs.csv`, `web_logs.csv`
- `current_architecture.png`
- Security test schedules (`.pdf`)

## 🇹🇷 Türkçe
**Acme Security**, siber güvenlik olaylarını incelemek ve analiz etmek için tasarlanmış açık kaynaklı bir laboratuvar reposudur. Gerçek dünyadaki siber olayları simüle eden önemli güvenlik belgelerini, mimari haritaları ve log kayıtlarını barındırır.

### ✨ Özellikler
- 📊 **Log Analizi**: Olayların derinlemesine incelenebilmesi için CSV formatında API, WAF, E-posta ve Web logları.
- 🗺️ **Sistem Mimarisi**: Mevcut sistem mimarisini detaylandıran görsel diyagramlar.
- 🗓️ **Planlama**: Güvenlik test programları ve gönderim (submission) raporları.

### 🛠️ İçerik
- `api_logs.csv`, `waf_logs.csv`, `web_logs.csv`
- `current_architecture.png`
- Güvenlik test programları (`.pdf`)
